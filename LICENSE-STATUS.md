# Licence status

No licence has been chosen for Bronzeward yet. The choice is the owner's and is tracked in
[ginsys/bronzeward#16](https://github.com/ginsys/bronzeward/issues/16). The repository carries no
LICENSE file until then, and no release is published.

`THIRD_PARTY_NOTICES.txt`, in every release archive, holds the licence and notice files of the
components that archive's binaries or web files include.
