# Changelog

Each release has a section here, headed by its tag. Every release is a pre-release
(`v0.N.0-alpha.M`) published on GitHub Releases only; none is published until the licence is
chosen ([ginsys/bronzeward#16](https://github.com/ginsys/bronzeward/issues/16)).

## v0.1.0-alpha.1

Not yet released. The first pre-release of the configuration-control proof of concept: the
`bronzeward` server for Linux, the `bronzewardctl` CLI for Linux and macOS, and the web interface
as static files with a reference Caddy configuration.
