# Changelog

Each release has a section here, headed by its version and date. A change records itself as a file
in `changelog.d/` (see its README); a release turns those files into its section. Every release is
a pre-release (`v0.N.0-alpha.M`) published on GitHub Releases only; none is published until the
licence is chosen ([ginsys/bronzeward#16](https://github.com/ginsys/bronzeward/issues/16)).
